Codex 实时用量面板 v1.0.4

快速开始
1. 解压整个 CodexUsagePanel 文件夹到固定位置。
2. 双击 CodexUsagePanel.exe，无需安装 Python 或 PowerShell。
3. 打开本机 Codex 并进入一个本地聊天，面板自动跟随。
4. 需要开机后自动待命时，在启动设置里勾选自动启动。
5. 可以创建桌面快捷方式。关闭设置窗口后，监听仍在后台运行。

重要：不要只复制 EXE；_internal 文件夹必须保留。
便携包适用于 Windows 10/11 x64；已在本机 Windows 11 验证。
当前程序未做数字签名。

新增 B 版蓝灰毛玻璃与矢量机器人动效，缩小时保留清晰字号；遵循系统透明效果和动画偏好，不支持毛玻璃时回退实色。

升级仍采用停止面板与监听后完整替换程序文件夹的方式；旧版便携包继续在 Releases 中提供。

新增工作区边界限制、边框拖动缩放和大小记忆；右键可恢复默认大小。详细操作见下方“面板操作”。

v1.0.2 自动启动修复
修复部分启动环境中“已勾选自动启动，但 Windows 登录后监听没有启动”的问题。

自动启动设置会核对 Windows 实际可见的记录，保留原有统计、面板操作及随 Codex 打开/关闭的行为。

面板操作
• B 版左侧为矢量机器人：空闲眨眼、生成中轻微点头、读取失败时琥珀色静止。悬停可查看实际状态；动画不是实时速度指示。
• 背景使用蓝灰毛玻璃，文字保持清晰。系统关闭透明效果、启用高对比度或原生材质不可用时自动使用实色；关闭系统动画时机器人保持静态。
• 点击“会话累计 / 最近调用”或旁边箭头，在带选中标记的菜单中选择范围；同时影响用量和缓存命中率，并保存偏好。
• “跟随中 / 固定会话”只显示状态，悬停可查看跟随方式与完整聊天名称。
• 点击“明细”展开，点击“收起”或按 Esc 返回原来的位置；屏幕底部会向上展开。
• 置顶按钮开启时显示选中底色；展开区“复制统计”复制当前范围的精确数据，并短暂显示“已复制”。
• 拖动面板空白处移动，右键菜单可打开启动设置。
• 面板不会被拖出当前显示器的可用工作区，也会避开任务栏；启动和屏幕布局变化后会自动找回越界位置。
• 鼠标拖动边缘或四角可调整大小，大小自动保存；右键“恢复默认大小”可重置。100% DPI 下最小横条约 730×45，标签保留至少 12 逻辑像素、核心数字至少 16 逻辑像素；极小工作区会进一步适配以保留控件。多屏拖动时跟随鼠标所在屏幕。
• 关闭 Codex 主窗口后，面板通常约 1～2 秒自动退出；重开后自动显示。
• 最小化 Codex 时继续显示。
• 手动关闭面板后，本次 Codex 打开期间不会反复弹出。
• 需要重新显示时，双击入口并点击“启动 / 显示面板”。

统计含义
• 总 token = 输入 + 输出；缓存输入、推理输出已分别包含其中。
• 明细左右两列分别展示输入、输出及其缩进子项，底部独立显示总用量；会话累计用量不代表当前上下文占用。
• 缓存命中率 = 缓存命中输入 / 输入；无有效计数时显示“—”。
• “均速 ≈ tok/s”始终为本轮最近一次已结算调用的平均生成速度，不随统计范围切换，不是逐 token 瞬时速度。
• 速度包含推理和工具参数输出，排除工具执行时间。
• 新一轮开始清空上一轮速度；缺少计时信息的旧日志显示“—”。
• 统计随 Codex 日志更新，通常在一次模型调用结束后结算。
• 底部保留最近调用摘要；详细公式、包含范围和刷新规则可悬停“统计口径 ⓘ”查看。
• “数据时间”对应统计记录时间，悬停看完整日期时间；空闲时保留上次记录，相对时间继续更新。
• 等待会话、读取中、等待统计及读取失败分别表示当前实际进度；读取失败的明细提供原因。空闲时显示“等待新的调用”，不会因为数据较旧而报连接异常。
• 读取异常或后台线程意外退出后会自动恢复；失败原因和恢复信息写入数据目录的 panel-error.log。正常空闲不会重启读取线程。
• 面板在其他应用前台时启动，也会优先通过 Codex 主窗口选择导航日志，避免误选同名辅助进程。
• 目前支持主窗口的本地聊天；远程、云端和多主窗口独立跟随尚未支持。

数据与配置
本工具只读本机日志和会话索引，不需要 API Key，运行时不发送网络请求。
默认会话目录：%USERPROFILE%\.codex\sessions
默认导航日志：%LOCALAPPDATA%\Codex\Logs
默认配置和状态：%LOCALAPPDATA%\CodexUsagePanel
首次使用无需手工配置。自定义路径见 README.md。
源代码模式会兼容现有 config.json 和旧运行状态目录。

停止、更新、移除
• 临时停止：启动设置 → 停止面板与监听。
• 更新：先停止，再完整替换程序文件夹；个人设置保存在用户目录。
• 移动目录：先取消旧位置自动启动，移动后再启用，并重新创建快捷方式。
• 完全移除：取消自动启动，停止面板与监听，再删除程序文件夹和快捷方式。
• 用户数据目录可保留或自行删除；不要删除 Codex 自己的 .codex 目录。

错误记录
启动失败查看数据目录中的 launcher-error.log。
旧源码入口可能使用 autostart-error.log；面板错误使用 panel-error.log。
请从入口打开配置目录查看详情。
