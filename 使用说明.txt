Codex 实时用量面板 v1.0.0

快速开始
1. 解压整个 CodexUsagePanel 文件夹到固定位置。
2. 双击 CodexUsagePanel.exe，无需安装 Python 或 PowerShell。
3. 打开本机 Codex 并进入一个本地聊天，面板自动跟随。
4. 需要开机后自动待命时，在启动设置里勾选自动启动。
5. 可以创建桌面快捷方式。关闭设置窗口后，监听仍在后台运行。

重要：不要只复制 EXE；_internal 文件夹必须保留。
便携包适用于 Windows 10/11 x64；已在本机 Windows 11 验证。
当前程序未做数字签名。

面板操作
• 点击累计/单次，切换会话累计和最近一次调用。
• 点击明细展开，收起后返回原来的位置；屏幕底部会向上展开。
• 拖动面板空白处移动，右键菜单可打开启动设置。
• 关闭 Codex 主窗口后，面板通常约 1～2 秒自动退出；重开后自动显示。
• 最小化 Codex 时继续显示。
• 手动关闭面板后，本次 Codex 打开期间不会反复弹出。
• 需要重新显示时，双击入口并点击“启动 / 显示面板”。

统计含义
• 总 token = 输入 + 输出；缓存输入、推理输出已分别包含其中。
• 缓存命中率 = 缓存命中输入 / 输入；无有效计数时显示“—”。
• ≈ tok/s 为本轮最近一次已结算调用的平均输出速度，不是逐 token 瞬时速度。
• 速度包含推理和工具参数输出，排除工具执行时间。
• 新一轮开始清空上一轮速度；缺少计时信息的旧日志显示“—”。
• 统计随 Codex 日志更新，通常在一次模型调用结束后结算。
• 目前支持主窗口的本地聊天；远程、云端和多主窗口独立跟随尚未支持。

数据与配置
本工具只读本机日志和会话索引，不需要 API Key，运行时不发送网络请求。
默认会话目录：%USERPROFILE%\.codex\sessions
默认导航日志：%LOCALAPPDATA%\Codex\Logs
默认配置和状态：%LOCALAPPDATA%\CodexUsagePanel
首次使用无需手工配置。自定义路径见 README.md。
源代码模式会兼容现有 config.json 和旧运行状态目录。

停止、更新、移除
• 临时停止：启动设置 → 停止面板与监听。
• 更新：先停止，再完整替换程序文件夹；个人设置保存在用户目录。
• 移动目录：先取消旧位置自动启动，移动后再启用，并重新创建快捷方式。
• 完全移除：取消自动启动，停止面板与监听，再删除程序文件夹和快捷方式。
• 用户数据目录可保留或自行删除；不要删除 Codex 自己的 .codex 目录。

错误记录
启动失败查看数据目录中的 launcher-error.log。
旧源码入口可能使用 autostart-error.log；面板错误使用 panel-error.log。
请从入口打开配置目录查看详情。
